## 🌐 Démo en ligne

Après activation de GitHub Pages : `https://[votre-username].github.io/maison-zoe/`

## 📁 Structure du projet

```

    ├── avis.html           ← Avis voyageurs (10/10)
    └── reservation.html    ← Formulaire → WhatsApp
```

## 🚀 Déploiement GitHub Pages

1. Créer un repository GitHub (ex : `maison-zoe`)
2. Uploader tout le contenu de ce dossier
3. Settings → Pages → Source : `main` / `(root)` → Save
4. Site disponible en 1-2 min
